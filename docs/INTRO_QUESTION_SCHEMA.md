# イントロ実践問題 正本スキーマ

## 目的

書籍の章別イントロ問題60問を、既存220問とは別の正本として保持します。正本を直接書き換えて一問一答に変換せず、正本IDを参照する派生問題を後から作成します。

## 問題形式

- `single_choice`: 単一選択
- `multiple_choice`: 複数選択
- `fill_match`: 穴埋め・組み合わせ
- `case_study`: 事例・運行計画
- `calculation`: 計算
- `image_choice`: 図・標識を使う選択問題

## トレーサビリティ

各問題は章・問番号・問題写真・解答写真を記録します。写真は照合用原資料として `source_docs/` または端末内に置き、公開物やGitには含めません。

## 派生問題

一問一答、音声、4択、模擬試験へ変換するときは、派生側に次を記録します。

- `sourceIntroId`: 元のイントロ問題ID
- `derivativeType`: 派生形式
- `reviewStatus`: 人間による確認状態

AIが派生問題を作成しても、元の正本、正解、解説は自動変更しません。

公開前は次の検査で、既存220問と試作5問の基本整合性を確認します。

```sh
python3 scripts/validate_study_data.py
```

## 公開時の注意

書籍写真は公開アプリへ掲載しません。図や標識が必要な問題は、権利上問題のない独自図版へ置き換えてから公開対象にします。
