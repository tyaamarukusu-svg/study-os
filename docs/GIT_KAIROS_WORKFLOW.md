# Git・KAIROS差分蓄積の運用

## 何が自動で保存されるか

Gitは、ファイルを編集・保存しただけでは履歴を確定しません。
AIが作業を終え、動作確認後にコミットした時点で、コード差分と判断理由が保存されます。

このプロジェクトでは、コミット時に次を必須とします。

1. 問題
2. 変更前
3. 判断理由
4. 変更内容
5. 変更後
6. 確認結果
7. 未解決

不足したコミットは `.githooks/commit-msg` が中止します。

## 週次レポート

`scripts/generate_weekly_kairos_report.sh` は、直近7日間のコミットをKAIROSレビュー用Markdownへまとめます。

出力先：

`reports/kairos-weekly/YYYY-MM-DD_study-os_git週次レポート.md`

毎週月曜日9時にCodexの週次オートメーションから実行します。
実行後は、生成したレポートの場所と対象コミット数を報告します。

レポートは正式なKnowledgeではありません。内容を確認し、採用するものだけBusiness OSへ反映します。

## 手動でレポートを作る場合

```sh
./scripts/generate_weekly_kairos_report.sh
```

## 今後のAIへの依頼

「変更して」と依頼すれば、AIは以下までを一つの作業として扱います。

1. 変更
2. 動作確認
3. 秘密情報確認
4. 判断理由付きコミット

pushは別扱いです。ユーザーが明示的に依頼した場合だけ実行します。
